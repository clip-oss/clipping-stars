## Image Optimization Notes

1. **HEIC to JPG Conversion**: Files ending in `.heic` must be converted to `.jpg` format
2. **Compression**: Large images (especially `A7400142.jpg` at 13MB) should be compressed for web
3. **Recommended max dimensions**:
   - Hero/Background images: 1920px wide
   - Client photos: 600x600px (square crop)
   - Results screenshots: 900px wide
   - Social proof photos: 800px wide

## Usage

Once all assets are placed in the correct folders with the correct filenames, simply open `index.html` in a browser to view the complete website.
